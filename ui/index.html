⚖ VouchGuard — on-chain vouch verification

Paste a proof URL (e.g. an X status that supposedly contains a vouch) and the handle that supposedly wrote it. The verdict comes from GenLayer consensus — validators fetch the page, an LLM extracts the evidence, and it's agreed with the equivalence principle. 
idle
Submit new checks from the CLI: node cli/vouchguard.mjs <contract> check <url> <handle>
